# Runtime license sources

These notices accompany the statically linked wasi-sdk 33.0 C/C++ runtime.
They are copied from the SDK's recorded source revisions:

- [wasi-libc 161b3195fc25](https://github.com/WebAssembly/wasi-libc/tree/161b3195fc25):
  the top-level license and three license texts; musl COPYRIGHT; cloudlibc
  LICENSE; musl-fts COPYING; the dlmalloc public-domain notice.
- [LLVM 4434dabb69916856b824f68a64b029c67175e532](https://github.com/llvm/llvm-project/tree/4434dabb69916856b824f68a64b029c67175e532):
  libc++, libc++abi, libunwind and compiler-rt LICENSE.TXT files.

The build's dependency/model notices are assembled separately by `package.py`.
